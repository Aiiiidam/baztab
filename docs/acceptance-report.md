## Not verifiable in this environment

- Docker images (web, worker, migrate) and the compose stack: Docker is not installed on the
  development machine; CI builds and smoke-tests them (`.github/workflows/ci.yml`, job `docker`).
- Live Supabase S3 contract and database TLS: the adapter is unit- and type-checked; the parallel
  infrastructure session's `scripts/supabase-smoke.ts` covers the live check once credentials are set.
